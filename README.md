# Terracotta Heritage Wedding Invitation

## Run
Open `index.html` in a browser.

## Customize
- Names/date/events: `index.html`
- Colors/design: `style.css`
- Animations/functions: `script.js`
- Music: put an MP3 at `assets/music/wedding-music.mp3`

## Important
The Google Maps search link is a placeholder based on “Sindhu Bhawan, Balaghat”. Replace it with the exact venue pin before publishing.
